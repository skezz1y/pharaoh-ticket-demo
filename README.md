# PHARAOH — независимый демонстрационный сайт

Статический адаптивный сайт. Откройте index.html или разместите три файла index.html, style.css, app.js на статическом хостинге / GitHub Pages (из корня ветки main).

Реализованы категории, выбор свободного места из 5 рядов, условно занятые места, пересчёт цены, валидация полей, модальное оформление и подтверждение демо-заказа. Форма не передаёт и не сохраняет персональные данные. Все предложения, цены и схема вымышлены. Нет настоящих платежей, отправки email, выпуска QR-билетов или проверки билетов продавцов. Не вводите реальные паспортные данные.

Для реального запуска потребуются backend, проверенный источник билетов и остатков, резервирование мест, платёжный провайдер с проверкой webhook, сервис отправки email и правила работы с персональными данными. Секреты должны находиться только на сервере. Нельзя выдавать действительный QR до подтверждения оплаты и права на билет.

Дизайн вдохновлён концертной эстетикой референса https://pharaoh.ru/, без копирования фотографий и без заявления об официальной связи. Шрифт Manrope загружается с Google Fonts, при отсутствии сети используется Arial.
